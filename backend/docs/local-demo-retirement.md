# 실제 장소 연결 후 로컬 데모 숨김

2026-11-17 사용자의 요청으로 로컬 개발 DB의 가상 장소 6곳을 HIDDEN(2)으로 전환했다. `scripts/hide-local-demo-places.sql`은 데모 생성기의 `[데모]` 이름, `(가상 주소)` 주소, 상위 지역의 `OUTPICK-DEMO-V1`/`OUTPICK-DEMO-GG` 마커가 모두 일치하고 TourAPI 수집 이력이 없는 장소만 처리한다. 재실행은 0곳을 처리한다.

가상 장소의 행을 물리 삭제하지 않으므로 필요하면 복원할 수 있다. 실제 장소가 재사용 중인 지역·분류·종목은 삭제하거나 변경하지 않는다. 실제 TourAPI 공개 장소 5곳과 사진·운영 안내는 유지한다. HIDDEN 장소는 기존 공개 검색·지도 데이터·상세 조회 규칙에 따라 제외된다.

일반 로컬 실행에는 `local` 프로필을 사용한다. `PlaceDemoData`는 테스트 및 명시적인 `demo` 프로필을 위한 개발 도구로 남겨 두며 일반 서버 시작 시 실행하지 않는다. 기존 로컬 데모 마커도 보존하므로 demo 생성기를 다시 실행해도 기존 가상 장소를 재생성하거나 재공개하지 않는다.

화면의 데모 경고는 현재 결과에 `[데모]` 장소가 있을 때만 표시한다. 실제 장소만 보이는 목록·지도·상세에는 가상 장소라는 안내가 나오지 않는다.
